halflife-gc

A generational garbage collector that predicts, before it allocates an object, whether that object will still be alive when the nursery fills up — and puts the ones that will straight into the old generation, so they are never copied.

Every number below is a deterministic event count from a simulator, not a wall-clock measurement. GC work = bytes traced + 2×bytes copied + 0.1×bytes swept. Lower is better. The model is trained on a profiling run of each program and scored on a different run with different input size and data.

GC work, relative to a stock generational collector

100% is the stock generational collector on that workload. Below 100% is a win. The oracle reads true object lifetimes off a recorded trace and is unshippable by construction — it is here to say how much there was to win at all.

How much of the available headroom the predictor recovered

The gap between the stock collector and the oracle is the prize. This is the share of it each policy actually collected.

The policy family: how long must an object live before pretenuring pays?

Pretenure an object if it will live at least K nurseries. K = 0 pretenures everything; large K pretenures nothing. Each curve is the perfect-knowledge collector swept over K, which shows both where the optimum sits and how sharp it is — a flat curve means the exact threshold barely matters, a sharp one means a predictor has to be right about when, not just whether.

The heap, playing

The same program, the same allocations, in the same order — twice. On the left, every object is born in the nursery and the survivors are copied out. On the right, the oracle puts the long-lived ones straight into the old generation. Watch the nursery: on the left it keeps handing objects over; on the right almost nothing survives it, which is exactly what a nursery is supposed to look like.

Prediction quality vs collector outcome

These two things come apart, and that is the interesting part. A model can have a respectable AUC and still make the collector worse, because the two mistakes do not cost the same: failing to pretenure a survivor costs one copy, while pretenuring garbage puts it in a space that is only collected by a full trace.
